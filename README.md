# cs450-ImitationGame

we are a school project that recreates imdb using relational databases at a very minimal level. only 6 entities.

Open index.html in browser to see changes, must reload on any change.

basic static HTML, JS, and CSS tech stack. Backend data storage is CSV

## 3 FEATURES

1. View all movies, actors, directors, and writers
2. filter movies by genre, year, title
3. if you click a movie, then you can see all fields about it and who acted in it

## TO RUN

use this command: python -m http.server 8080
then connect to: [http://localhost:8080/index.html](http://localhost:8080/index.html)
Its needed because we are using a library to parse the CSV files
